Types & I/O Data Interfaces Map

Every Any in the codebase sits on one of five data boundaries. This map documents the concrete shape that actually flows through each one — traced field-by-field from source — and the target type that replaces the Any. Notable: a large share of the Any surface sits on dead or vestigial code, and most of the "missing" types already exist.

The five boundaries

Data enters from tinyagent (the LLM runtime), splits into the streaming event path (right) and the session state path (left), and exits to disk and to rendered panels. Each labeled edge is a boundary where types go untyped today.

Target type design PLAN

The deliverable of #441: each block below names a real contract and kills a bucket of Any.

1 · Use the alias that already exists

Replace args: dict[str, Any] | None with args: ToolArgs | None across ui/renderers/ and ToolCallPartProtocol. ~35 sites, zero behavior change.

2 · Per-tool arg TypedDicts

# types/tool_args.py — total=False: model output is untrusted;
# renderers keep their .get() defaults
class BashArgs(TypedDict, total=False):
    command: str
    timeout: int

class ReadFileArgs(TypedDict, total=False):
    filepath: str
    offset: int

class WriteFileArgs(TypedDict, total=False):
    filepath: str
    content: str

class WebFetchArgs(TypedDict, total=False):
    url: str
    timeout: int

class HashlineEditArgs(TypedDict, total=False):
    filepath: str

3 · Session persistence TypedDicts

class SessionFileV1(TypedDict):
    version: int
    session_id: str
    project_id: str
    created_at: str
    last_modified: str
    working_directory: str
    selected_skill_names: list[str]
    current_model: str
    session_total_usage: dict[str, object]
    thoughts: list[str]
    messages: list[dict[str, object]]
    compaction: CompactionPayload | None

class SessionSummary(TypedDict):
    session_id: str
    created_at: str
    last_modified: str
    message_count: int
    current_model: str
    file_path: str

list_sessions() → list[SessionSummary] fixes state.py, the protocol, and session_picker.py in one stroke.
